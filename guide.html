API reference

Two layers, one canvas. Use hotAndReady for complete charts; use the core API for your own drawing. They work together, and both expose the same canvas context.

CHART HELPERS

hotAndReady

Data and settings in; a complete chart out. These helpers draw series, axes, labels, legends and tooltips.

linePlot(data, settings)Multiple series, labels, tooltips, time axes

Pass a settings object, even if empty. Data maps column names to numeric arrays.

SettingDefault / behavior
inputs / outputs["xs"] / ["ys"]. One input name per output name.
title / xLabel / yLabel"Untitled" / "x" / "y".
legendLabels["y"]. Supply one label per series; an empty string hides that entry.
colorsRed, green, orange, blue, purple, yellow; cycles through the array.
lineWidth2 canvas pixels.
tooltips[]; column names to show near a hovered point.
autoScaletrue; first draw only. Reset alreadyAutoScaledLinePlot to request it again.
xmin, xmax, ymin, ymaxOverride the initial automatic extent. Ignored when autoScale is false.
xTicks / yTicksCanvas width / 120 and height / 80, rounded down. Supply positive counts for very small plots.
xAxisIsTime / yAxisIsTimefalse; format millisecond timestamps as dates/times.
locale / timeZoneOptional Intl locale and IANA timezone. Supplying either enables locale-aware, span-adaptive time labels. Omit both for the original tick-label format.
timeFormatOptional Intl.DateTimeFormatOptions, such as { month: 'short', day: 'numeric' }. Applied to time axes and date tooltips.
xTickFormat / yTickFormatOptional (value) => string callbacks. Override numeric or time tick labels independently, while keeping the axis coordinates numeric.
tooltipFormattersMap column names to (value, index) => string. Date columns on time axes are formatted automatically; callbacks override that formatting.
barPlot(data, settings)Category labels, colors, automatic scaling

Data is { bars: string[], heights: number[] }. Settings: title, xLabel, yLabel, legendLabels, colors and autoScale. Their defaults match line plots except that bars autoscale every draw. The stable helper uses its built-in bar width and tick layout.

histogram(values, settings?)Bin raw samples and count observations

Accepts a numeric array or {values}. Non-finite samples are skipped. Returns bin bounds, counts, and heights.

plot.hotAndReady.histogram([1, 2, 2, 3, 5, 8])

OptionBehavior
binsNumber of bins. Defaults to the rounded-up square root of the sample count, capped at 1,000.
rangeOptional [min, max] bounds. Samples outside the range are skipped. The last bin includes max.
densityScale heights so the total bar area is one. Off by default.
gapFraction of each bin left blank, 0.06 by default.

Try it in the playground →

pieChart / donutChartPart-to-whole charts

Pass nonnegative values, or {values, labels}. Both methods accept the same options.

plot.hotAndReady.pieChart([45, 28, 17, 10])

OptionBehavior
labelsOptional slice names. Percentage labels are used by default. Legends use supplied names or generated slice names.
innerRadiusHole radius as a fraction of the chart radius. Defaults to zero for pie and 0.55 for donut.
startAngleStarting angle in radians. Defaults to the top of the circle.
showLabels / labelColorShow or hide labels and set their color.
showLegendShow the legend, true by default. Use labels or legendLabels to name slices.
showTooltipsShow slice name, value, and percentage on hover. True by default. The donut hole does not trigger a tooltip.
labelFormatter / tooltipFormatterOptional (value, index, fraction) callbacks returning text. Set showLabels to false to hide labels inside the slices.

Try it in the playground →

boxPlot(values, settings?)Compare quartiles, whiskers, and outliers

Pass one numeric array or an object of named arrays. Returns quartiles, median, whisker endpoints, and outliers for each group.

plot.hotAndReady.boxPlot({ A: [1, 2, 3, 5], B: [3, 4, 8, 9] })

OptionBehavior
whiskerFactorWhiskers reach the last observations within 1.5 interquartile ranges by default.
showOutliersDraw observations outside the whiskers. On by default.
boxWidthWidth in group units, 0.55 by default.

Try it in the playground →

scatterPlot / bubblePlotPaired points with optional size

Pass {xs, ys}. An optional radii array overrides the radius per point. bubblePlot accepts the same input.

plot.hotAndReady.bubblePlot({ xs: [1, 2], ys: [3, 5], radii: [4, 12] })

OptionBehavior
radiusDefault marker radius in CSS pixels. Defaults to 4.
opacityMarker opacity. Defaults to 0.8.

Try it in the playground →

areaPlot(data, settings?)Fill a series down to a baseline

Pass {xs, ys} in drawing order.

plot.hotAndReady.areaPlot({ xs: [0, 1, 2], ys: [2, 5, 3] })

OptionBehavior
baselineData value to fill to, zero by default.
opacityFill opacity, 0.26 by default.
lineWidthOutline width, 2 by default.

Try it in the playground →

heatmap(rows, settings?)Map a grid of numbers to color

Pass rows as nested arrays. Row zero appears at the top. Missing and non-finite cells are skipped.

plot.hotAndReady.heatmap([[1, 4], [2, 8]])

OptionBehavior
rangeOptional [min, max] for color normalization. Defaults to the data extent.
colorsA palette from low to high.
colorScaleOptional (value, fraction) => color callback. Fraction is clamped to 0–1.
axesShow numeric grid axes. Off by default.

Try it in the playground →

Shared settings & tooltipColors, labels, axes, and custom tooltips

Chart helpers run inside drawingLoop. The new helpers take an optional settings object. Set color or colors, title, and axis labels as needed. For Cartesian charts, use axes: false to hide axes or autoScale: false to keep your own bounds. Automatic bounds update when the data extent changes.

hotAndReady.drawTooltip(x, y, info) draws key/value pairs near a data coordinate.

CORE CANVAS API

Canvas, on your terms

Draw inside drawingLoop. Coordinates and paths are yours; ctx remains the native 2D context.

Element attributesBounds, padding, rendering and controls

Set numeric values with setAttribute(name, String(value)). Boolean attributes use the strings "true" and "false", rather than HTML’s presence/absence convention.

AttributeDefaultMeaning
xmin, xmax−100, 100Horizontal bounds in data units.
ymin, ymax−100, 100Vertical bounds in data units.
xpadding, ypadding10, 16Padding at each edge, as a percentage of canvas width/height.
framerate30Target drawing frequency, not a guaranteed rate.
fontsize25Font size in canvas pixels for plot labels.
default-axes-ontrueDraw default axes after your drawing function; plot helpers manage their own axes.
controlsEnabledString true/false attaches/removes mouse pan and wheel zoom listeners. Touch handling remains separate.
Themes & colorsBrowser preference, graph toggle, and color overrides
SettingBehavior
themeAttribute or property. auto by default, or light / dark.
resolvedThemeThe current resolved mode, light or dark. Read only.
show-theme-toggleThe corner theme button is shown by default. Set this attribute to false to hide it.
themeColorsAssign an object with any of background, foreground, axes, border, muted, tooltipBackground, legendBackground, sliceLabel, or palette. Assign null to reset.
axisColor / textColorOptional per-call overrides for drawAxis and drawDefaultAxes. drawLabel accepts color.
Element & drawing loopdrawingLoop, ctx, canvas, rendering, DPI
MemberBehavior
drawingLoopYour callback. Use an arrow closure over the plot, or a regular function bound with .bind(plot).
ctx / canvas / shadowThe 2D context, underlying canvas, and open shadow root.
renderPlot()Refresh bounds/scales, clear, draw, and synchronize linked values once.
fixDPI()Check CSS dimensions, update canvas resolution if needed, and redraw. The existing implementation uses dpr = 2 by default.
debugDefaults to true; set false to silence attribute-change logging.

Wrap custom drawing in ctx.save() / ctx.restore() to keep colors and styles from leaking into default axes.

Coordinates & pathsScales, lines, arcs and rectangles
MemberBehavior
scaleX(x), scaleY(y)Data coordinate → canvas pixel coordinate.
scaleXInverse(x), scaleYInverse(y)Canvas pixel coordinate → data coordinate.
updateScales()Recompute the mappings; useful after directly assigning numeric bounds.
drawLine({xs, ys}, lineWidth = 2)Stroke a polyline in data coordinates, keeping the previous line width.
arc(cx, cy, r, start, end, counterclockwise = false)Append a sampled arc in data coordinates; angles in radians. The full-circle example passes true explicitly.
rect(x, y, width, height)Append a rectangular path in data coordinates.
Axes & labelsCustom axes, time formatting and labels

Use the same locale, timeZone, timeFormat, xTickFormat and yTickFormat options in drawDefaultAxes. For drawAxis, use tickFormat for its one axis, and isDatetime: true for timestamps.

MemberBehavior
drawLabel(settings)Pixel x/y and text; optional theta (radians), font, textAlign, textBaseline. Theta rotates counterclockwise.
drawDefaultAxes(settings = {})Draw axes with optional xTicks, yTicks, xAxisIsTime, yAxisIsTime.
drawAxis(settings)Custom axis: data x1/y1/x2/y2, labelXOffset/labelYOffset in data units, labelTheta in radians, nTicks, and either labels or scaleStart/scaleEnd. Optional isDatetime.
Interaction & linkingHit testing, pointer state and shared bounds
MemberBehavior
mouseInCircle(cx, cy, r)Test the pointer in data units; false when outside the canvas.
mouseInRect(x1, y1, x2, y2)Test the pointer against two opposite corners, inclusively.
mouseX / mouseY / mouseDownCurrent pointer position in data units, or undefined outside; left button state.
linkInfo(keys, object)Share named element values through one common object.

Drag to pan; scroll to zoom around the pointer. Scroll below the x axis to zoom x alone, or left of the y axis to zoom y alone. Two-finger touch gestures pan and zoom, with axis-specific behavior in the margins. These are the original controls, including their existing quirks.

A plot, from plain JavaScript.

Load one script, create an easy-canvas, and give it a drawing function. No special HTML needed. Save this complete example as index.html and open it in a browser, or open the standalone example.

<!doctype html>
<html lang="en">
<meta charset="utf-8">
<title>My first EasyCanvas plot</title>
<script src="https://jackeown.github.io/EasyCanvas/easyCanvas.bundle.js"></script>
<body>
<script>
const plot = document.createElement('easy-canvas');
plot.style.cssText = 'display:block; width:100%; height:360px';
document.body.appendChild(plot);

const data = { xs: [0, 1, 2, 3, 4], ys: [1, 3, 2, 5, 4] };
plot.drawingLoop = () => {
  plot.hotAndReady.linePlot(data, {
    title: 'My first plot',
    xLabel: 'Time', yLabel: 'Value'
  });
};
</script>
</body>
</html>

Prefer markup? Use <easy-canvas id="my-plot" style="display:block;height:360px"></easy-canvas> and get it with document.getElementById('my-plot'). Either way, give the element a real width and height.

The script registers the custom element automatically. Load it once, before your plotting code. You can also download the bundle and use a relative script URL.

Arrays in. Lines out.

Data is an object of arrays. The names are yours to choose: inputs and outputs pair up the columns to draw. Repeat an input for multiple series sharing the same x values.

Drag to pan. Scroll to zoom. Hover near a line for its values.

const xs = Array.from({ length: 161 }, (_, i) => i / 20);
const data = {
  xs,
  sine: xs.map(Math.sin),
  cosine: xs.map(Math.cos)
};
const plot = document.querySelector('#lines');
plot.drawingLoop = () => {
  plot.hotAndReady.linePlot(data, {
    title: 'A couple of waves',
    xLabel: 'x', yLabel: 'Amplitude',
    inputs: ['xs', 'xs'],
    outputs: ['sine', 'cosine'],
    legendLabels: ['Sine', 'Cosine'],
    colors: ['#2457dc', '#df6846'],
    tooltips: ['xs', 'sine', 'cosine']
  });
};

For tooltips, use one shared input column with x values sorted in ascending order. All paired arrays should have matching lengths. Use at least two points and nonzero axis ranges.

A simple bar chart.

Supply category names in bars and matching values in heights. Hover a bar to highlight it. This helper is best suited to nonnegative values with a positive maximum.

Example data, not actual dessert sales. Controls are disabled on this demo.

const plot = document.querySelector('#bars');
const data = {
  bars: ['Cake', 'Pie', 'Donuts', 'Cookies'],
  heights: [12, 8, 19, 15]
};
plot.drawingLoop = () => {
  plot.hotAndReady.barPlot(data, {
    title: 'An entirely made-up bake sale',
    xLabel: 'Dessert', yLabel: 'Sold',
    legendLabels: data.bars,
    colors: ['#2457dc', '#df6846', '#43a18b', '#9273b9']
  });
};

Bar plots autoscale on every draw by default. Set autoScale: false to use your own bounds. Set the element’s controls="false" explicitly when you want a static chart.

Zooming & panning

Mouse controls are enabled when a canvas is created. Try them on the linked plots below to see how two views move together.

ActionControl
PanHold the left mouse button and drag.
Zoom around the pointerScroll over the plot area.
Zoom just the x axisScroll in the margin below the x axis.
Zoom just the y axisScroll in the margin to the left of the y axis.
Touch navigationUse two fingers to pan and pinch to zoom.

Use plot.setAttribute('controls', 'false') to disable mouse panning and wheel zoom. The existing two-finger touch handlers are separate from that switch.

For a line plot, request a fresh view of the data with plot.alreadyAutoScaledLinePlot = false; plot.renderPlot(). Or set xmin, xmax, ymin, and ymax to choose your own bounds.

Linked plots

Pass the same object to linkInfo and tell each plot which bounds to share. The plot under the pointer publishes its bounds; the others follow.

Pan or zoom either plot. Their x ranges move together.

const link = {};
const xs = Array.from({ length: 161 }, (_, i) => i / 20);
for (const [id, fn, title] of [
  ['linked-sine', Math.sin, 'Sine'],
  ['linked-cosine', Math.cos, 'Cosine']
]) {
  const plot = document.getElementById(id);
  plot.linkInfo(['xmin', 'xmax'], link);
  const data = { xs, ys: xs.map(fn) };
  plot.drawingLoop = () => {
    plot.hotAndReady.linePlot(data, {
      title, xLabel: 'Shared x', yLabel: 'Value',
      colors: ['#2457dc']
    });
  };
}

Add 'ymin' and 'ymax' to link both axes. Each canvas gets one link object and one list of keys; calling linkInfo again replaces them.

Custom drawing

plot.ctx is the real 2D context. Helpers such as arc, rect and drawLine take data coordinates; the native context takes canvas pixels. Use scaleX and scaleY to move between the two.

Move over the circle. Hit testing uses your data coordinates.

const plot = document.querySelector('#custom');
plot.setAttribute('xmin', '-2');
plot.setAttribute('xmax', '2');
plot.setAttribute('ymin', '-1.5');
plot.setAttribute('ymax', '1.5');
plot.drawingLoop = () => {
  plot.ctx.save();
  plot.ctx.strokeStyle = '#2457dc';
  plot.ctx.fillStyle = plot.mouseInCircle(0, 0, 0.6)
    ? '#df6846' : '#dce5ff';
  plot.ctx.beginPath();
  plot.arc(0, 0, 0.6, 0, 2 * Math.PI, true);
  plot.ctx.closePath();
  plot.ctx.fill();
  plot.ctx.stroke();
  plot.ctx.restore();
};

arc and rect add to the current path. Call ctx.beginPath() first, then fill or stroke it yourself. Circles stretch if your x and y scales have different pixel sizes. drawLabel takes canvas pixel coordinates.

Animation & live data

EasyCanvas clears the canvas and calls drawingLoop automatically, targeting 30 frames per second by default. Use elapsed time for animation so speed is independent of frame rate.

A moving wave drawn with the low-level line helper. Save and restore the context to keep the axes neutral.

const plot = document.querySelector('#animation');
plot.setAttribute('xmin', '0');
plot.setAttribute('xmax', '8');
plot.setAttribute('ymin', '-1.5');
plot.setAttribute('ymax', '1.5');
plot.setAttribute('framerate', '30');
const xs = Array.from({ length: 161 }, (_, i) => i / 20);
plot.drawingLoop = () => {
  const t = performance.now() / 1000;
  plot.ctx.save();
  plot.ctx.strokeStyle = '#2457dc';
  plot.drawLine({ xs, ys: xs.map(x => Math.sin(x - t)) });
  plot.ctx.restore();
};

For changing data, mutate the arrays your drawing loop reads, or replace the data variable. A line plot autoscales on its first draw only, so your view survives panning and zooming.

// The drawing loop reads the same object every frame.
data.ys.push(7);
data.xs.push(5);

// Line plots autoscale once, preserving subsequent zoom/pan.
// Explicitly request fresh bounds when your data needs them:
plot.alreadyAutoScaledLinePlot = false;
plot.renderPlot();

framerate="0" stops regular animation after the initial frame; it is not a full pause switch. Resizing, the DPI timer, pointer interactions and explicit renderPlot() calls can still redraw. Keep drawing functions free of unintended side effects.

Themes & colors

Each graph starts in theme="auto", following the browser’s light or dark preference. The small button in the graph’s corner switches between light and dark. Return to the browser preference with plot.theme = 'auto'.

Choose a mode with plot.theme = 'dark' or plot.theme = 'light'. The HTML form works too: <easy-canvas theme="dark"></easy-canvas>.

Override individual colors with plot.themeColors = { background: '#102b26', axes: '#8cd8c2', foreground: '#e5fff5' }. Set plot.themeColors = null to restore the theme defaults. Chart-level colors, color, and labelColor settings take precedence for their own marks. Custom drawing can set ctx.fillStyle or ctx.strokeStyle directly.

Dates & time

Use Unix timestamps in milliseconds and set xAxisIsTime: true (or yAxisIsTime). Time axes use millisecond timestamps, including sub-second values. Labels adapt to the visible time span. The default is the browser’s local timezone; choose an explicit timeZone and locale for predictable formatting. Try the controls below.

Drag to pan, scroll to zoom, or switch the time span. Hover a line for the full timestamp.

Synthetic temperatures, not real measurements. timeFormat accepts Intl date/time fields; xTickFormat overrides individual tick labels. Reset view restores the selected span after zooming.

const plot = document.querySelector('#dates');
const start = Date.UTC(2026, 0, 1);
const time = Array.from({ length: 85 }, (_, i) => start + i * 7200000);
const data = {
  time,
  temperature: time.map((_, i) => 18 + 3 * Math.sin(i / 5)),
  forecast: time.map((_, i) => 18 + 2.5 * Math.sin(i / 5 + 0.3))
};
plot.drawingLoop = () => {
  plot.hotAndReady.linePlot(data, {
    title: 'A week of temperatures',
    inputs: ['time', 'time'], outputs: ['temperature', 'forecast'],
    xLabel: 'Time · UTC', yLabel: 'Temperature (°C)',
    legendLabels: ['Observed', 'Forecast'],
    colors: ['#2457dc', '#df6846'],
    xAxisIsTime: true, timeZone: 'UTC', locale: 'en-GB', xTicks: 6,
    tooltips: ['time', 'temperature'],
    tooltipFormatters: { temperature: value => `${value.toFixed(1)} °C` }
    // Optional: timeFormat: { month: 'short', day: 'numeric' }
    // Or: xTickFormat: value => new Date(value).toISOString().slice(0, 10)
  });
};

The same API, with types.

Download easyCanvas.d.ts beside your application source. It describes the existing browser API and adds easy-canvas to TypeScript’s element map. Use type-only imports; the browser bundle still provides the runtime.

import type { EasyCanvasElement, LinePlotSettings }
  from './easyCanvas'; // easyCanvas.d.ts, downloaded beside this file

// Load easyCanvas.bundle.js once in your HTML, before this app.
const plot = document.createElement('easy-canvas');
plot.style.cssText = 'display:block; height:360px';
document.body.appendChild(plot);

const settings: LinePlotSettings = {
  title: 'From TypeScript', inputs: ['x'], outputs: ['y']
};
plot.drawingLoop = () => {
  plot.hotAndReady.linePlot({ x: [0, 1, 2], y: [2, 1, 4] }, settings);
};

// Existing elements can be checked and typed too:
const existing = document.querySelector<EasyCanvasElement>('#my-plot');

This declaration file works with the stable JavaScript bundle documented here. The original TypeScript implementation and its example remain on the typescript branch; it has some different behavior and is not silently substituted for the stable version.

A small wrapper, on purpose.

EasyCanvas was made to keep plotting simple while leaving the underlying canvas available. It uses browser custom elements, a shadow-root canvas, and an automatic drawing loop. There is no framework or runtime package dependency. The library requests the Lato font from Google Fonts; drawing still works if that font is unavailable.

Optional rich text

Load easyCanvasRichText.js after the bundle and call enhanceEasyCanvas(plot, { richText }). The callback receives (context, text, x, y, font, align, color). Return true if you drew the text, or false to let canvas draw it. This opt-in mode draws on demand. Call plot.requestRender() after changing data or drawingLoop. Call plot.disposeRichRendering() to restore the normal animation loop.

Where the source lives

The stable CommonJS source is easyCanvas.js, easyCanvasHotAndReady.js, and helpers.js. easyCanvas.bundle.js is the browser-ready build used by the original blog posts. The browser bundle is built from those sources. Time formatting extensions are optional; the original plotting and drawing APIs remain available. The typescript and masks branches retain the later experiments.

Run locally

git clone https://github.com/jackeown/EasyCanvas.git
cd EasyCanvas
python3 -m http.server 8766
# Open http://localhost:8766

No install or build is needed to read the docs or use the bundle. For library development, npm ci installs the build/typecheck tools; npm run build rebuilds the browser bundle and npm test checks the declarations and documentation. Review any rebuilt bundle before committing it.

Things to know

  • Use a visible element with a nonzero size. A block display and explicit height are the easiest setup.
  • Line autoscaling needs finite numeric data and nonzero ranges. For a flat series, provide distinct ymin/ymax overrides.
  • The existing implementation installs timers and animation callbacks per element without a teardown API. Prefer reusing a plot over repeatedly creating and removing elements.
  • Load the bundle only once per page. Custom elements cannot be registered twice.
  • The stable bundle is a classic script, not an ES module export. The declarations describe its DOM API; they do not add a runtime import.
